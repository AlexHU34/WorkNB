# NEBULA BLOOM — как устроен проект

Каталог из трёх игр и редактора. Каждая часть лежит в своей папке,
и понятно, зачем она нужна.

## Что где

| Папка | Что внутри | Нужна ли тебе |
|---|---|---|
| `index.html` | страница с каталогом 3D-игр | это готовая игра |
| `lang.html` | редактор кода BloomScript | да |
| `studio.html` | студия сцен | да |
| `src/app/` | логика каталога и сто игр | нет, это внутреннее |
| `src/engine/` | 3D-движок на WebGL2 | нет |
| `src/lang/` | язык BloomScript | нет |
| `src/studio/` | внутренности студии | нет |
| `src/data/` | диагностика ошибок, доступность | нет |
| `src/types/` | подсказки для редактора кода | нет |
| `tools/` | проверки качества и сборка | только если что-то чинишь |
| `docs/` | планы и заметки | по желанию |
| `dist/` | результат сборки, готовые сжатые файлы | нет, пересоздаётся |

## Три важных правила

**1. Готовые игры — это три файла, а не папка.**
`dist/min/` содержит `NebulaBloom.html`, `BloomScript.html`,
`NebulaStudio.html`. Именно они копируются в папку с играми. Их
можно отправить кому угодно: открыл файл — игра работает, без
интернета и без установки.

**2. Проверки запускаются все сразу.**
```
python tools/all-gates.py            # всё
python tools/all-gates.py --light    # быстрая часть, ~3 минуты
```
Это 21 проверка: синтаксис, сто игр, 3D-движок, редактор, студия,
сохранение, доступность, офлайн, описания типов и другие. Если
проверка падает — она сама говорит, что именно сломалось.

Гейты идут **по одному**, а не одновременно. Это не медлительность:
по одному все проверки занимают около трёх минут, а одновременно
они растягивались до девяти и начинали зависать. Подробности в
`tools/all-gates.py`.

**3. Перед тем как отдать файлы, проверь.**
```
python build.py
```
Соберёт всё, сожмёт и прогоняет проверки по собранному файлу.

## Как добавить игру

Игры лежат в `src/app/games.js`, каждая — функция вида
`MODES.имя = function(){...}`. Имя становится адресом игры.
Список игр для меню — в `src/app/data.js`.

После правки:
```
python tools/run-tests.py        # сто игр должны пройти
python build.py
```
