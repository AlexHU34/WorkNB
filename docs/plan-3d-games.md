# BloomBlox — План 5 3D-игр + встраивание в один файл

> Ограничение: всё в одном `index.html`, без внешних библиотек (работа офлайн).
> Поэтому «3D» = честный псевдо-3D: CSS 3D-трансформы, изометрия на canvas, рейкастинг.
> Все 5 игр используют общую инфраструктуру: `awardResult()` (монеты/XP/звёзды),
> `setProg()`, `modeCleanup()`, звуки `sfx`, конфетти `boom()`.

---

## Архитектура встраивания (уже реализована в файле)

- У игры в `GAMES[]` есть поле `mode: "mem" | "run3d" | ...`. Если поля нет — обычный конструктор.
- `openGame()` при `g.mode` прячет панель деталей (`#gameView.mode-on .hideInMode`)
  и вызывает `MODES[g.mode]()` — режим рисует себя в `#canvas` через `modeRoot()`.
- Кнопка «Готово» вызывает `saveClick()` → `modeFinish()` режима (или подсказку).
- `stopMode()` при выходе чистит таймеры/rAF/слушатели и удаляет `.mode`-узлы.
- Двойная награда исключена: `awardResult()` после выдачи подменяет `modeFinish` заглушкой.

## Игра 15. 🏎 3D-Забег (псевдо-3D дорога, canvas)

- **Картинка:** горизонт, трапециевидная дорога из сегментов, жёлтое солнце, разметка.
- **Геймплей:** ёж 🦔, 3 ряда (←/→), сущности летят вглубь (z 110→0, масштаб = 1−z/120).
  🌸 собирать (+1), 🪵 уворачиваться (−1 ❤, всего 3). 45 секунд.
- **Звёзды:** ≥25 🌸 → 3, ≥15 → 2, иначе 1. Рекорд ≥25 открывает ачивку `run`.
- **Строк кода:** ~70. Риск: низкий.

## Игра 16. 🏪 3D-Тайкун (изометрия, canvas)

- **Картинка:** изометрические ромбы-грядки 4×3 с боковыми гранями (fake-3D объём),
  проекция `sx=320+(x−y)*72, sy=110+(x+y)*36`.
- **Геймплей:** старт 120 🌸. Инструменты: купить горшок (20) → посадить (10) →
  полить (ускорение x2) → продать цветок (~30–45). Рост по тикам 1.2с.
  Цель — капитал 400 (автопобеда + бонус 40 🌸).
- **Звёзды:** 400 → 3, 300+ → 2, 200+ → 1. Ачивка `tycoon`.
- **Строк кода:** ~90. Риск: низкий (вся экономика внутри игры, глобальный баланс не ломает).

## Игра 21. 🌸 3D-Цветок (CSS 3D)

- **Картинка:** сцена `perspective:900px`, цветок `preserve-3d`, лепестки
  `rotateZ(i*360/N) translateY(−58px) rotateX(38°)`, центр-сфера `translateZ(24px)`.
- **Геймплей:** кнопка «+лепесток» (до 16), своя палитра, автоповорот с паузой,
  drag по сцене крутит `rotateX/rotateZ`. Таск показывает счётчик и просит разные цвета.
- **Звёзды:** ≥12 лепестков и 3 цвета → 3, ≥8 → 2. Финиш через общую кнопку «Готово».
- **Строк кода:** ~60 + 15 CSS. Риск: низкий.

## Игра 22. 🌀 3D-Лабиринт (рейкастинг, canvas)

- **Картинка:** 160 лучей, DDA по карте 8×8, fisheye-коррекция, z-буфер,
  спрайты-эмодзи (🌸, 🚪/🔒) с отсечением по глубине.
- **Геймплей:** WASD/стрелки + экранные кнопки. Собрать 3 🌸 → дверь открывается →
  дойти до 🚪. Счётчик времени в таске.
- **Звёзды:** <60с → 3, <120с → 2. Ачивка `maze`.
- **Строк кода:** ~110. Риск: средний (самая сложная; вся математика стандартная,
  карта закрыта стенами — лучи не улетают).

## Игра 23. 🗼 3D-Башня (fake-3D стек, canvas)

- **Картинка:** блоки-прямоугольники со светлой верхней гранью, качающийся блок сверху,
  скорость растёт с высотой.
- **Геймплей:** клик/пробел сбрасывает блок; засчитывается пересечение с нижним,
  свес срезается; промах (<14px) −1 ❤ (всего 3). Идеальное попадание ±10px = +3 🌸.
  Цель — 12 этажей.
- **Звёзды:** 12 → 3 (авто), 8+ → 2 через досрочный финиш.
- **Строк кода:** ~70. Риск: низкий.
