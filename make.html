AERIS

Свою игру можно сделать прямо в браузере. Без установки, без регистрации, за десять минут.

Шаг 1. Открой редактор

Нажми кнопку ниже. Откроется редактор кода. Он работает и без интернета.

✎ Открыть редактор ◈ Открыть студию
Если хочется не писать код, а просто собрать сцену из кубов и шариков — это студия. Она превращает сцену в готовый код.

Шаг 2. Скопируй эти строчки

Это игра, которая уже работает. Вставь её целиком и нажми «Запустить».

// Моя первая игра: куб падает и ловится мышью.

fn setup():
  let s = "cube"
  bg("#87ceb9", "#cde7f0")
  add(s)

let x = 0
let y = 0
let vy = 0
let caught = 0

in update(dt):
  vy = vy + 9 * dt
  y = y + vy * dt

  if key(KEY_SPACE) and y <= 0.001:
    vy = 9

  x = clamp(x + (mouse.x * 2 - 1) * 4 * dt, -1, 1)

  if y <= 0:
    y = 0
    vy = 0
    caught = caught + 1
    tree.glow(cube(0.5, 0.5, 0.5, "#7ad4a2"))

in draw():
  camera(0, 5, -14)
  ground(60, 60, "#d7dde3")
  let cube = box(x, 0.5 + y, 0, 0.9, 0.9, 0.9, "#2a2a2c")
  h.glow(cube, 0.7)
  text("Поймано: " + str(caught), 0, 4, 0, "#a6207f")

Шаг 3. Нажми «Запустить»

Игра откроется справа. Управление мышью и пробелом.

Что можно поменять сразу

  • #2a2a2c — цвет куба. Восемь знаков: # и шесть символов.
  • 9 — насколько сильно куб падает. Больше значит быстрее.
  • 0.9 — размер куба.
  • text(...) — надпись на экране.

Шаг 4. Что делать, если не выходит

Редактор говорит, что именно не так, и добавляет подсказку, что делать дальше. Чаще всего это отступ: строки внутри блока сдвигаются на два пробела вправо.

Справка по всем командам — в самом редакторе, раздел «Справка». Там же есть самопроверка: она запускает твой код и показывает, что он делает.

Шаг 5. Покажи результат

Кнопка «Опубликовать» кладёт твою игру в общий каталог — она появится рядом со встроенными. Кнопка «Файл» в студии сохраняет сцену файлом на компьютер, его можно переслать другу.

Сейчас опубликованные игры хранятся в твоём браузере. Когда наберётся много игр, их можно будет выложить на сайт для всех — это следующий шаг.
